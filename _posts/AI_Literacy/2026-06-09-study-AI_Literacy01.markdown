# 프롬프트란 무엇인가?

<aside>
💡

AI에게 전달하는 지시/질문/맥락/조건의 총체 — “AI와 나누는 첫 번쨰 대화”

</aside>

---

## 프롬프트의 4가지 핵심 구성 요소 (PCIF)

1. **역할지정**(Persona): AI에게 어떤 전문가처럼 행동할지 지정
    - 당신은 10년 경력의 마케팅 전문가입니다
2. **맥락**(Context): 배경 정보, 제약 조건, 대상 독자 제공
    - 대상: 2030 여성, 톤: 친근하고 활기차게
3. **지시**(Instruction): 수행할 작업을 구체적으로 명시
    - 신제품 출시 SNS 카피를 3가지 작성해주세요
4. **출력형식**(Format): 원하는 결과 형태와 길이를 지정
    - 각 카피는 2문장 이내, 이모지 포함

<aside>
💡

**4가지 요소가 모두 포함될수록 AI응답의 정확도와 품질이 급격히 향상됩니다**

</aside>

---

## 좋은 프롬프트 작성 5가지 원칙

1. **명확성**(Clarity): 모호한 표현 금지. ‘좋은 글’ 대신 ‘300자 이내 뉴스 헤드라인 스타일’로 구체화하세요.
    - BEFORE: ‘좋은 이메일 써줘’
    - AFTER: ‘팀장에게 보내는 업무 진행 보고 이메일, 3 단락, 200자 이내’
2. **맥락 제공**(Context): 배경 정보가 많을수록 AI는 더 적합한 답을 생성합니다. 역할/상황/목적을 설명하세요.
    - 역할: ‘당신은 ~입니다’, 상황: ‘~한 상황에서’, 목적: ‘~을 위해’
3. **구체성**(Specificity): 수치/분량/조건을 명시하세요. ‘길게’가 아닌 ‘800~1000자’, ‘몇가지’가 아닌 ‘3가지’.
    - 숫자로 말하기: ‘몇 가지’ → ‘5가지’, ‘길게’ → ‘500자 이상’
4. **형식지정**(Format): 원하는 출력 형태를 명시하세요. 표/목록/코드블록/Json/마크다운 등을 지정합니다.
    - ‘결과를 표 형태로’, ‘마크다운 코드 블록으로’, ‘JSON 형식으로 출력’
5. **반복개선**(Iteration): 첫 응답이 완벽하지 않아도 됩니다. ‘더 자세히’, ‘다른 관점으로’, ‘더 짧게’등으로 개선하세요.
    - 프롬프트는 대화입니다 — 결과를 보고 수정/보완하는 것이 정상

## 핵심 프롬프트 엔지니어링 기법

### Zero-shot Prompting

예시 없이 바로 지시하는 기법

```
지구 온난화의 원인 3가지를 설명해 주세요
```

활용: 간단하고 명확한 작업

### Chain-of-Thought (CoT)

“단계적으로 생각해 주세요” — 복잡한 추론 유도

```
A=3, B=5일 때 A+Bx2를 단계별로 계산해 주세요
```

활용/수학/논리/추론 문제

### Few-shot Prompting

2~5개 예시를 제공하여 패턴을 학습시키는 기법

```
긍정: 맛있다 -> 좋음
부정: 별로다 -> 나쁨
-> "신선하다" 분류는?
```

활용: 일관된 형식/분류 작업

### Role Prompting

AI에게 특정 전문가 역할을 부여하는 기법

```
당신은 경험 많은 응급실 의사입니다.
두통의 원인을 분류해 주세요.
```

활용: 전문적 답변이 필요할 때

<aside>
💡

기법들을 조합하면 더 강력한 프롬프트가 됩니다: Role + Few-shot + CoT = 전문가 수준 답변

</aside>

---

## 핵심 정리

- 프롬프트 = AI에게 전달하는 역할/지시/맥락/형식의 총체
- 좋은 프롬프트는 명확성/맥락/구체성/형식/반복 개선의 5원칙을 따른다
- 나쁜 프롬프트: 짧고 모호 / 좋은 프롬프트: 역할/조건/형식이 명시된 구체적 지시
- Zero-shot / Few-shot / CoT / Role Prompting 등 기법을 조합하면 전문가 수준 응답 가능
- 프롬프트 능력 = AI 시대의 핵심 리터러시 — 같은 AI, 다른 결과

# 프롬프트 4요소 학습

## Persona 역할 지정

> AI에게 특정 전문가 역할/성격/관점을 부여하여, 해당 분야에 최적화된 시각으로 답변하게 만드는 설정
> 

### 왜 중요한가?

- 동일 질문도 역할에 따라 깊이와 관점이 달라짐
- 전문성 시뮬레이션 — 경험 없이도 전문가 수준 답변
- 통/어조를 역할에 맞게 자동 조절

<aside>
💡

‘당신은 [직함]입니다’ 또는 ‘~처럼 행동하세요’ 형태로 문장 맨 앞에 배치

**핵심**: Persona = 전문성의 방향타 — ‘누가’ 말하느냐에 따라 답변의 깊이와 관점이 완전히 달라진다

</aside>

---

## Context 맥락 제공

> AI가 최적 답변을 생성하도록 배경 정보/상황/대상/제약 조건/목적을 제공하는 요소
> 
- **목적**(Purpose): 왜 이 작업을 하는가
- **대상**(Audience): 누가 읽을 것인가
- **상황**(Situation): 어떤 상황/배경인가
- **제약**(Constraint): 조건/한계 사항은
- **배경**(Background): 이미 알고 있는 사전 정보

<aside>
💡

**Tip**: 5가지 중 관련 있는 것을 입력 — 많을수로 정확하지만 핵심만 간결하게

**핵심**: Context = AI의 네비게이션 — 목적지(목표)와 현재 위치(상황)를 알려야 최적 경로를 찾아간다

</aside>

---

## Instruction 지시 사항

> AI에게 ‘무엇을’, ‘어떻게’ 수행할지 명확히 지시하는 핵심 명령부 — 프롬프트의 심장부
> 

### 좋은 지시문의 원칙

1. 동사로 시작
    - 작성해, 분석해, 비교해, 요약해, 번역해, 생성해
2. 구체적 목표
    - ‘설명해’대신 ‘3가지 원인을 원인-결과 순으로 설명해’
3. 단계 지정
    - ‘단계별로’, ‘먼저~그다음~마지막으로’ 순서 명시
4. 수량 명시
    - ‘몇 가지’대신 ‘정확히 5가지’, ‘2~3문장으로’

### 지시문 해부

- **ACTION**: 핵심 동사 — 무엇을 할지
- **SUBJECT**: 대상 — 무엇에 대해
- **METHOD**: 방법 — 어떻게
- **CRITERION**: 기준 — 어떤 관점으로

<aside>
💡

**Tip**: Action + Subject + Method + Criterion 4가지가 모두 있으면 완벽한 지시문

**핵심**: Instruction = 설계도 — 목표와 방법이 구체적일수록 AI는 완성도 높은 결과물을 만든다

</aside>

---

## Format 출력 형식

> AI 응답의 구조/길이/스타일/출력 방식을 정확하게 지정하여 바로 활용 가능한 결과물을 얻는 요소
> 
- 구조 형식
    - 표(Table) 형태로
    - 번호 목록으로
    - 불릿 포인트로
    - 계층 구조로
- 길이 제어
    - 200자 이내로
    - 3문단으로
    - A4 1장 분량으로
    - 50단어 이하로
- 스타일
    - 마크다운으로
    - HTML 태그 포함해
    - JSON 형식으로
    - 코드 블록으로
- 전달 방식
    - 결론 먼저 제시해
    - 단계별로 설명해
    - 예시를 포함해
    - FAQ 형태로

<aside>
💡

**Tip**: 포맷이 없으면 AI가 임의로 선택 — 활용 목적에 맞는 형식을 항상 명시할 것

**핵심**: Format = 포장지 — 내용이 같아도 형식에 따라 즉시 활용 가능 여부가 갈린다.

</aside>
